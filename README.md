# Tribe & Tree — website mockup

A three-page mockup for **Tribe & Tree Social Club**, a members-only cannabis
social club and dispensary at **72 Bree Street, Parys, Free State**.

| Page | File |
| --- | --- |
| Home | `index.html` |
| Info (about, membership, house rules, hours, FAQ) | `info.html` |
| Contact (details, message form, map) | `contact.html` |

It's plain HTML/CSS/JS with no build step. Open `index.html` in a browser,
or serve the folder with any static host (GitHub Pages, Netlify, Vercel).

- `styles.css` — the whole theme (forest green, bone, ochre, clay; Fraunces + DM Sans)
- `script.js` — 18+ age gate, mobile menu, opening hours + "open now" status, mock form

## Details to confirm with the club

Anything shown with a dashed ochre highlight on the site is a placeholder:

- Phone, WhatsApp and email (`contact.html`)
- Instagram / Facebook links (footer of every page)
- Sunday hours and public-holiday hours (`HOURS` in `script.js`)
- Membership fee and payment methods (`info.html`)

Hours are currently Mon–Thu 7am–8pm, Fri–Sat 7am–10pm, taken from the club's
Rolling Stoner listing. Public listings disagree, so check them with the club.

Remove the "Design mockup" banner at the top of each page before going live.
The contact form doesn't send anything yet. Hook it up to a form service, or
